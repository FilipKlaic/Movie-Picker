# Movie Night Picker

Stop spending more time picking a movie than watching one.

A simple web app that picks a random movie for you based on genre, release year, and minimum rating — powered by the TMDB API.

## Features

- Filter by genre, release year, and minimum IMDb rating
- Three quality modes:
  - **Balanced** — a mix of popular and lesser-known films
  - **Popular favorites** — high vote count, crowd-pleasing picks
  - **Hidden gems** — lower popularity but highly rated
- Re-roll to get a new suggestion without changing your filters
- Swedish streaming region support (SE)

## Getting Started

1. Get a free API key from [TMDB](https://www.themoviedb.org/settings/api)
2. Add it to `config.js`
3. Open `index.html` in your browser — no build step needed
